# Nathaliya (PVT) LTD – Production Tracking System

A production tracking and inventory management system developed for **Nathaliya (PVT) LTD** to manage production activities, stock movements, inventory records, and operational information.

## 📌 About the Project

The **Nathaliya (PVT) LTD – Production Tracking System** is a web-based management system designed to help a company efficiently manage its production-related activities and inventory operations.

The system provides a centralized platform for recording production information, managing stock movements, monitoring inventory levels, and generating useful reports.

## ✨ Key Features

- 📊 Dashboard overview
- 📦 Product management
- 📥 Stock In management
- 📤 Stock Out management
- 🔄 Inventory balance tracking
- ⚠️ Low-stock monitoring
- 🔎 Product and stock search
- 📋 Production record management
- 📑 Production and inventory reports
- 🖨️ Print reports
- 📄 PDF report generation
- 📊 Excel report generation
- 📝 Word report generation
- 📱 Responsive user interface

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP
- phpMyAdmin

## 🗂️ System Modules

### 1. Dashboard
Provides an overview of production and inventory information through a simple dashboard.

### 2. Product Management
Allows users to add, update, view, and manage product information.

### 3. Stock In
Records incoming stock and maintains accurate inventory records.

### 4. Stock Out
Records outgoing stock and updates the available inventory balance.

### 5. Inventory Management
Tracks available stock quantities and identifies products that require attention.

### 6. Production Tracking
Maintains production-related records and helps monitor production activities.

### 7. Reports
Generates reports related to production, stock movements, and inventory information.

## 🎯 Project Purpose

The main purpose of this system is to improve the management of production and inventory activities within **Nathaliya (PVT) LTD** by reducing manual record keeping and providing organized, accessible, and accurate information.
